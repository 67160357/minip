# WattWise — Storytelling Dashboard

Dashboard เชิงเล่าเรื่องของธุรกิจ WattWise (อุปกรณ์ NILM ตรวจจับการใช้ไฟรายเครื่อง) รายวิชา Business Idea Creation

## โครงสร้าง
- `dashboard/index.html` — Dashboard (เปิดไฟล์ได้เลย ต้องต่ออินเทอร์เน็ตเพื่อโหลด Chart.js และฟอนต์)
- `data/` — ข้อมูลที่ใช้: `appliance_daily.csv`, `hourly_profile.csv`, `business_projection.csv`
- `scripts/make_data.py` — สร้างข้อมูลทั้งหมด (`python3 scripts/make_data.py`)
- `members.md` — รายชื่อกลุ่ม
- `assets/` — โลโก้จากสไลด์แบรนด์

## เรื่องที่เล่า
ปัญหา (บิลไม่บอกใครกินไฟ) → ค้นพบ (สัดส่วนรายเครื่อง) → พฤติกรรมรายชั่วโมง → สัญญาณเตือนแอร์ → คุณค่าต่อลูกค้า → โมเดลธุรกิจ → ความเสี่ยง

## ที่มาของข้อมูล (ข้อมูลจำลองทั้งหมด)
ไม่มีข้อมูลมิเตอร์จริง ข้อมูลสร้างด้วย seed คงที่ ตัวเลขธุรกิจอ้างอิงสไลด์ของกลุ่ม:
- ราคาอุปกรณ์ 3,500 บาท (ช่วง 2,500–4,500) · ซับสคริปชัน 149 บาท/เดือน (ช่วง 99–299)
- สมมติเอง: ต้นทุนอุปกรณ์ 1,800 บาท, ลูกค้าซับสคริปชัน 40%, ติดตั้ง 15% ของยอดขาย (800 บาท/ครั้ง), ยอดขายใหม่ 1,000 / 2,500 / 4,500 ชุดในปีที่ 1–3, ค่าไฟ 4.2 บาท/หน่วย, การตลาด 15% ของรายได้
- แอร์เสื่อมสภาพช่วง 10 วันสุดท้ายเพื่อสาธิตฟีเจอร์ Predictive Maintenance
